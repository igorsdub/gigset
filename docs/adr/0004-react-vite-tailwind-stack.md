# React, Vite, and Tailwind CSS Stack for GitHub Pages

We require a modern, client-side web framework capable of high-performance rendering for musical notation grids, rich interactive drag-and-drop setlist management, and seamless offline operation. We decided on React, TypeScript, Vite, and Tailwind CSS, deploying as a static single-page application (SPA) to GitHub Pages via GitHub Actions. This gives us zero-cost hosting, mature component tooling, and instantaneous client-side navigation without backend latency.
