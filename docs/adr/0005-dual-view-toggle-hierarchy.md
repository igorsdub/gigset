# Dual View Toggle Hierarchy

Musicians in different roles (e.g. vocalists vs rhythm section) or different moments in a song need either full lyrics with chord anchors or a concise iReal-style measure form. We decided to provide view toggling at both the individual Song Card level and globally via a Master View Toggle in the Event header. This allows users to default the entire set to chord grid or lyrics while still allowing individual songs (such as an instrumental solo or lyric-heavy ballad) to override their display mode.
